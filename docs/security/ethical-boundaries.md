# Ethical Boundaries

Veil is a self-control aid for the person who owns and operates the device. It is not a parental-control system, employee-monitoring product, partner-monitoring tool, or covert surveillance mechanism.

## Non-negotiable rules

1. The user must initiate protection and understand what each permission enables.
2. Screen processing must remain local in the MVP; no screen content may be uploaded or sold.
3. Veil must display an honest active-protection state and must not use stealth behavior.
4. Accessibility data must be limited to the minimum events required for the user-facing protective function.
5. Interventions must be calm, non-shaming, and oriented toward recovery rather than punishment.
6. Emergency access and essential phone functions must remain available.
7. Any feature that enables a third party to observe, control, or score another person's device is outside the product mission.

These boundaries are product requirements. They should be tested through code review, privacy review, release checklists, and documented architecture decisions rather than treated as aspirational copy.
