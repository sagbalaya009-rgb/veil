# Acceptance evidence matrix

Implemented source and executed validation are separate. See [the delivery report](../releases/ENGINEERING_DELIVERY_REPORT.md) for the exact final commit/run/APK and evidence. The API35 seven-test suite has executed successfully; physical and semantic qualification remain distinct.

| Acceptance area | Executed evidence | Remaining qualification |
| --- | --- | --- |
| Builds and installs | Actual cloud Gradle debug/test/release packaging; emulator installs and MainActivity launches | Physical TECNO installation and signed release runtime |
| First launch/navigation | Fresh API35 onboarding, dashboard, Focus disclosure and cancellation pass | Other tabs' complete flows, largest font, TalkBack and physical layouts |
| Persistence | Actual Room settings/notes save, close and reopen; private commitment snapshot, actual expired-record XML/backup pruning and safe-exit assertions pass | Same-boot process death, reboot and OEM lifecycle scenario |

| Delivery | Source branch and draft PR; actual debug APK, packaging, checksum and evidence | Owner signing and any separately authorized publication |

Synthetic geometry is deliberately an optimized false positive. Its numeric trigger proves integration, not appropriate classification of explicit content. The one-minute focus result measures real elapsed expiry, not phone performance. Source sampling/buffer bounds and desktop timings are not TECNO battery/thermal/latency measurements. Permission revocation, force-stop/uninstall and protected surfaces are intentional Android limits.
