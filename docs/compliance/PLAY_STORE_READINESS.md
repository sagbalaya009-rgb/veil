# Google Play readiness

Status: not submitted, not approved. A debug APK is not a production release or evidence of Google Play acceptance.

Before publication, the owner must complete and verify:

- A privacy policy and Data Safety answers consistent with the shipped binary. Screen processing is local; screenshots, text and browsing content must remain absent from telemetry, storage, support bundles and crash logs. Review every added SDK.
- The Accessibility API declaration and reviewer video. Explain voluntary self-control, package-only window observation, dismissible overlay use, prominent disclosure, affirmative consent, and revocation. This product must not misrepresent itself as a disability accessibility tool.
- Foreground service declaration for mediaProjection, user benefit, user initiation, visible indication and stopping behavior. No boot or hidden restart path may be introduced.
- Accurate store copy: no claims of universal capture, guaranteed porn detection, unbreakable restriction, child surveillance, anti-uninstall enforcement or bypassing secure windows. Clearly identify medical/art/anatomy false positives and protected-content false negatives.
- A real model's license, source attribution, redistribution obligations, preprocessing, checksum, evaluation and limitations. Any release that cannot initialize a valid classifier must visibly disable screen analysis.
- Target-SDK requirements, signing ownership, release build validation, required review access, content rating, age audience, dependency disclosures and device testing against the current Play Console requirements at submission time.
- Install/launch, consent denial and grant, notification denial, access revocation, Android system stop, process kill, reboot, rotation, lockscreen, battery restrictions, app transitions, overlay exit, focus persistence and false-positive escape tests on actual supported devices.

Current policy research and links are in [Android permissions](ANDROID_PERMISSIONS.md). No legal, policy or model approval is inferred from a local metadata file. Publication requires explicit owner authorization and production credentials; neither is created or assumed here.
